Solmar Bay is a 3D open-world crime game built with three.js: explore a sun-soaked coastal city on foot and by car, steal cars, evade the police as your wanted level rises, and run three story missions — a delivery, a getaway, and a harbor heist. Original city, characters, and story.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
